KRX FDR

국내 주식의 이동평균 돌파를 찾아 차트로 확인합니다

KOSPI, KOSDAQ, 한국 ETF의 시세를 주봉과 월봉으로 정리하고, 이동평균선을 상향 돌파한 종목을 골라 보여 줍니다.

[요약]

실시간 시세가 아니라, 수집 시점 기준의 조회 도구입니다.

대상KOSPI, KOSDAQ, 한국 ETF. ETN과 스팩은 스캔에서 제외합니다.
찾는 것주봉 10, 240이평과 월봉 10, 120, 180, 240이평의 상향 돌파입니다.
흐름데이터 저장 → 돌파 서칭 → 결과 조회 순서로 씁니다.
사용법왼쪽 메뉴에서 돌파 종목, 종목 차트, 주요 종목을 조회합니다.
참고용 자료입니다. 이 앱의 정보는 투자 권유가 아니며, 정확성과 최신성을 보장하지 않습니다. 투자 판단과 그 결과의 책임은 이용자에게 있습니다.

세 가지 버전

코드는 하나이고, 실행 방법에 따라 메뉴와 화면이 달라집니다.

버전실행메뉴차트
메인streamlit run web_app.py시작화면, 1~8번, 사용 가이드대화형
경량python web_app_lite.py시작화면, 1~4번, 사용 가이드이미지
서버Streamlit Cloud시작화면, 돌파 종목 조회, 종목 차트 조회, 주요 종목, 사용 가이드대화형

경량과 서버 버전에는 관심저장 기능이 없고, 서버 버전에는 데이터 저장과 스캔 메뉴도 없습니다.

빠른 시작

프로젝트 폴더에서 실행해야 화면 테마가 적용됩니다.

pip install -r requirements.txt
streamlit run web_app.py
pip install -r requirements.txt
python web_app_lite.py
  1. 1. 데이터 저장에서 전체 업데이트를 누릅니다. 처음에는 전체 이력을 받아 오래 걸립니다.
  2. 2. 이평 돌파 종목 서칭에서 스캔 실행을 누릅니다.
  3. 3. 서칭 데이터 조회에서 결과를 봅니다.
시작화면의 "오늘의 작업"을 보면 어느 단계까지 끝났는지 알 수 있고, 단계를 누르면 해당 메뉴로 이동합니다. 평일 공휴일은 구분하지 않아, 데이터가 최신이어도 데이터 저장이 미완료로 나올 수 있습니다.

1. 데이터 저장

시세를 받아 일봉, 주봉, 월봉과 이동평균을 만듭니다.

  • 전체 업데이트: 평소에 쓰는 버튼입니다. KOSPI, KOSDAQ, ETF와 지수를 함께 갱신합니다.
  • 시장별 업데이트: 접힌 영역에 있습니다. 특정 시장만 다시 받을 때 씁니다.
  • 이미 최신이면: 버튼을 한 번 더 눌러야 실행됩니다.
시장별 업데이트 뒤에는 주의하세요. 시장마다 기준일이 다르면 경고가 나옵니다. 그 상태로 스캔하면 기준일이 섞이므로 전체 업데이트를 먼저 하세요.

2. 이평 돌파 종목 서칭

스캔 실행을 누르면 전체 종목을 검사하고 차트 이미지를 만듭니다. 메뉴를 옮기거나 새로 고침해도 스캔은 계속됩니다. 오늘 스캔이 이미 있으면 한 번 더 눌러야 실행됩니다.

cmd에서는 프로젝트 폴더에서 다음과 같이 실행합니다.

scan

돌파 종목 조회 (3. 서칭 데이터 조회)

가장 최근 스캔의 돌파 종목을 봅니다.

  1. 정렬과 필터를 고릅니다. 돌파율 필터와 볼륨% 필터는 "최대" 값 이하만 남깁니다.
  2. 케이스 버튼을 누릅니다. 괄호 안 숫자는 필터 적용 후 건수입니다.
  3. 이전, 다음 버튼이나 아래 썸네일로 종목을 옮겨 다닙니다.
  • 강도순: 돌파율이 낮은 종목부터 나옵니다. 이평선에 막 올라선 종목이 먼저 보입니다.
  • 봉 표시: 차트 위에 봉 날짜와 확정 봉 또는 진행 중 봉이 나옵니다.
  • 관심저장: 분류와 메모를 입력하고 현재 확대 종목 관심저장을 누르면 이번 달 관심 파일에 저장됩니다.
썸네일의 강조 표시는 현재 종목과 다를 수 있습니다. 현재 위치는 4/155 같은 표시로 확인하세요.

종목 차트 조회 (4. 관심종목 서칭)

  1. 종목 선택 방식을 고르고 종목코드를 입력하거나, 종목명 앞 2글자로 찾습니다.
  2. 연도와 월일로 기준일을 정합니다. 월일은 0315 또는 3-15처럼 씁니다.
  3. 봉 타입에서 주봉이나 월봉을 고르고 종목 차트 조회를 누릅니다.
  4. 이전 1봉, 다음 1봉으로 기준봉을 옮깁니다.

기준일 이후의 시세는 보여 주지 않습니다. 그 시점의 차트를 복기하기 위한 동작입니다.

분류와 메모를 입력하고 현재 차트 데이터 저장을 누르면 이번 달 관심 파일에 저장됩니다.

5. 관심종목 조회

  • 관심 파일 선택에서 월을 고릅니다. 예전 watch.csv도 고를 수 있습니다.
  • 표에서 행을 선택하고 차트 또는 삭제를 누릅니다.
  • 차트에는 저장 시점의 가격선과 "기준" 표시가 나옵니다. 처음위치로는 저장 시점으로 돌아갑니다.
  • 메모를 고치고 메모저장을 누릅니다.

6. 패턴 데이터 입력

종목 차트 조회와 같은 화면입니다. 차트를 본 뒤 기록 파일명, 분류, 메모를 정하고 현재 차트 데이터 저장을 누르면 패턴 기록 파일에 저장됩니다.

7. 패턴 데이터 조회

위쪽 요약표에서 파일별 행 수를 보고, 기록 파일 선택에서 파일을 고릅니다. 표에서 행을 선택하고 차트를 누르면 저장 시점 기준의 차트가 나옵니다.

8. 보유 종목 조회

  • 보유 종목 추가: 종목명 앞 2글자로 찾아 매수가, 수량, 메모를 입력합니다.
  • 보유 종목 데이터: 현재 종가, 수익률, 주봉·월봉 이평과의 이격도를 보여 줍니다.
  • 차트: 행을 선택하고 누르면 매수가 선이 함께 나옵니다.
  • 삭제: 삭제할 때 관심종목으로 옮길지 고를 수 있습니다.

주요 종목

메뉴를 누르면 KOSPI와 KOSDAQ의 최신 거래일 종가, 등락률과 KOSPI 주봉이 먼저 나옵니다. 등락률은 상승 빨강, 하락 파랑입니다.

  • 지수: KOSPI, KOSDAQ
  • 종목: 삼성전자, SK하이닉스, 삼성전기
  • 항목을 고르면 주봉이 먼저 나오고, 차트 위에서 주봉과 월봉을 바꿀 수 있습니다.
당일 값의 기준: 실시간이 아니라 마지막으로 수집한 거래일의 값입니다. 카드의 날짜를 확인하세요.

데이터와 용어

용어뜻

이동평균5, 10, 20, 120, 180, 240. 거래량이 없는 봉은 계산에서 제외

스캔에서 제외하는 것

  • ETN, 스팩
  • 거래량이 없는 봉
  • 직전 주·월보다 오래된 돌파 (거래가 멈춘 종목의 옛 돌파 방지)

데이터의 한계

  • 실시간 시세가 아니며, 수집과 스캔을 실행한 시점의 값입니다.
  • 분할·병합 등이 있으면 과거 시세가 재조정되지 않았을 수 있습니다.
  • 월초의 월봉은 거래일이 적어 볼륨%가 낮게 나옵니다.

서버 배포

코드는 공개 저장소, 데이터는 비공개 저장소의 Release에 둡니다. 서버는 데이터를 받아 보여 주기만 합니다.

  • 진입점: lite/streamlit_app.py, 브랜치 main
  • 이 PC 환경변수: KRX_DATA_REPO, KRX_DATA_TOKEN(쓰기 토큰)
  • 서버 Secrets: 같은 이름, 읽기 전용 토큰
  • 수동 업로드: python scripts/publish_lite_data.py

자세한 절차와 겪은 문제는 lite/deploy.md에 있습니다.

토큰은 코드와 문서에 적지 마세요. 만료되면 업로드와 내려받기가 실패하니 만료일을 관리하세요.
