예상 배당액은 사용자가 입력한 1주당 월 세전 금액 × 현재 보유 수량입니다. 예상액이 0이면 배당 없음으로 목록과 합계에서 제외하며, 기존 배당 분류 종목의 미입력은 확인 필요로 표시합니다. 해당 월에 29~31일이 없으면 말일로 표시합니다. 휴일·실제 지급일 변경·세금은 자동 반영하지 않습니다. 계좌 내 예상 입금액이며 연금계좌에서 생활비로 인출 가능한 금액과는 다릅니다.

시세 연결 범위

KOSPI · KOSDAQ · 국내 ETF 종목 마스터와 기존 일별 CSV를 읽습니다. 미국 종목은 티커·현재가를 직접 입력할 수 있습니다. 미국 자동 시세·세금 가이드는 후속 범위입니다. ETF의 자산 유형·투자대상·성장/배당 분류는 직접 지정합니다.

현재 수량으로 과거 가격을 곱한 값을 실제 과거 자산으로 만들지 않습니다. 아래 차트는 직접 저장한 평가 기록만 사용합니다.

업데이트 서버 실행

브라우저의 HTML은 Python을 직접 실행할 수 없습니다. 아래 실행 파일을 받아 열면 명령어 입력 없이 서버와 시장·종목 화면이 시작됩니다.

실행 파일 받기 (.cmd)

다운로드한 portfolio_dashboard_start.cmd를 한 번 열어주세요. 이미 실행 중인 이 프로젝트의 서버가 있으면 재사용합니다. 처음 실행할 때는 파일을 직접 열어야 합니다.

HTML 직접 열기와 서버 주소·포트가 달라지면 저장공간도 달라집니다. 기존 입력이 있다면 현재 화면에서 JSON 저장 후 새 서버 화면에서 불러오세요.
